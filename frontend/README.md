# EtymoMind · 词根脉络思维导图

以思维导图串联「词根 → 单词 → 音标 → 释义 → 构词 → 例句」六层信息的英语词汇记忆工具。

## 功能

- **浏览模式**：完整展示六层导图，可点击喇叭播放单词 / 例句发音
- **模式A · 默写单词**：只保留 词根 → 单词 → 释义 → 例句 四层，单词改为输入框，例句中的目标词同步遮挡
- **模式B · 考核释义**：隐藏中文释义（构词拆解中的引申义同步遮挡），答出任一义项即可
- **学习看板**：正确率、用时与练习明细，记录保存在浏览器 localStorage

快捷键：答题时 `Enter` 跳到下一题，`Ctrl/⌘ + Enter` 提交；看板中 `Esc` 关闭。

## 开发

```bash
npm install
npm run dev     # 本地开发
npm run build   # 类型检查 + 打包
npm run lint    # oxlint
```

词根数据位于 `src/mock/roots.ts`，判分规则位于 `src/utils/grading.ts`。
